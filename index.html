F1 · Career Services

Job Fair Registration

This form is for current students or alumni that wish to register for the job fair hosted next week. It will take roughly 2-5 minutes to complete.

F1 · Before You Register

Please fill out the form to register. Required fields are marked as (required). Email is required as it is tied to your student account. Name and job type choices will help us find partnered employers for possible interview opportunities on the spot. All your information will be processed through us and is strictly used within the institution.

You will get a confirmation email after submission.

State matrix
State What The User Sees Non-color Cues Expected Behavior
Default Empty fields, unchecked boxes, unselected radios, default select/dropdown, empty textarea. Labels, help text, placeholders and "required" is there when it is a required field. Fill in fields and check and select form options/inputs.
Focus When tabbing, the selected field is highlighted by a highlighted border. Visible outline around the focused field or control. User can start typing information or select it/check it.
Required An empty field, but with a label that explicitly says "required". A "(required)" text appears in the label, and the attribute will warn the user with the error warning box if they don't enter a correct email. User has to enter a correct email to be able to submit the form.
Valid The name field has a valid name. The field has a label and a typed value inside. The entered name is submitted without any form validation errors.
Invalid An entered value with a red container, and an error message. An error message explaining the expected input. User has to correct their student ID input.
Disabled A button is disabled and the user can't click it to submit. Button is greyed out, can't be clicked, and has an unavailable icon on the cursor. Nothing happens when clicking the button. The action is unavailable.
Server-returned error An error message warning the user about wrong email entered. The error messages describes that the email entered does not exist. The user has to contact Career Services.
